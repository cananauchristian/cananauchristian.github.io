# MSX Portal

Persönliches Startportal für Media Station X.

## Einrichtung

In Media Station X unter:

`Settings → Start Parameter → Setup`

folgenden Startparameter mit geschlossenem Schloss eintragen:

`cananauchristian.github.io`

## Enthaltene Apps

- Lampa
- MSXPlayer v4
- Offizieller MSX Launcher
- Seasonvar

## Struktur

- `msx/start.json` – Einstiegspunkt
- `msx/menu.json` – Hauptmenü
- `msx/apps/` – separate Zwischenseiten
- `msx/shared/` – gemeinsame Fehlerseiten
- `docs/apps.md` – App-Adressen und Hinweise

Externe Dienste können ihre Adressen oder Verfügbarkeit jederzeit ändern.
